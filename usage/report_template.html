7 · Extension blueprint (from outline.txt)

1. Track

Use an active-tab timer + chrome.history, not History durations (they run on in background tabs; this report has to collapse overlaps). Log per URL: domain, path type (e.g. /shorts/* vs /watch), active seconds, hour.

2. Score

Ship the category table from §1 / §9 as defaults, with per-device overrides. Split huge domains by path (Shorts 10, Watch 35, Search 40, localhost 95). Let the user move News → Entertainment (the toggle above). Recompute the weighted score live.

3. Report + Block

Weekly card (see §6). Nudges: Shorts quota, Watch session cap, wind-down after 23h, news cap 20 min/day. You already own BlockTube/DF-Tube, so reuse their block lists.

Phone: Brave Android has no extensions, so the extension can't run there. Phone data comes from this repo's adb collectors. On-device nudges would need Android's Digital Wellbeing app timers (e.g. on Brave / YouTube) or a launcher-level limit.
